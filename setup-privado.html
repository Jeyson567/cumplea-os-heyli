Instalación de un solo uso

Primer administrador

Esta pantalla inicia sesión, muestra el UID y comprueba el documento que ya creaste en Firestore. No concede el permiso y no crea otra cuenta.

  1. Ábrela con un servidor local. No la abras como archivo ni la publiques.
  2. Entra con el correo del administrador. La contraseña no se guarda en el código.
  3. Comprueba que el UID coincida con el documento admins/UID de la base (default).
  4. Ese documento debe tener el campo active como booleano en true. Esta página no puede escribirlo.
  5. Pulsa Ya autoricé este UID. Si la comprobación es válida, irás a admin.html.
